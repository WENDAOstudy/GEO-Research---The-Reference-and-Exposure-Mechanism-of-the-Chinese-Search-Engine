# 公开发布检查清单

在将仓库设为 Public 前，请逐项确认：

- [ ] 已确认数据不含姓名、手机号、身份证号、账号凭证等不应公开的信息。
- [ ] 已确认网页标题、链接和正文片段的采集及再分发符合来源网站条款和著作权要求。
- [ ] 已确认自己有权为数据库结构、整理成果及可授权内容选择许可证。
- [ ] 已选定开放数据许可证，并在仓库根目录添加 `LICENSE` 文件。
- [ ] 主数据压缩包小于 GitHub 普通 Git 的单文件大小限制。
- [ ] 已使用 `SHA256SUMS.txt` 核对上传前后的文件校验值。
- [ ] 已检查 README 中的记录数、版本号和更新日期。

可考虑的数据许可证包括 CC BY 4.0、CC0 1.0 和 ODC-By。许可证应根据数据权属、署名要求和再利用目标选择，不应自动套用到无权授权的第三方内容。
