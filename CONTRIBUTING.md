# Contributing

Contributions that improve documentation, metadata, validation, or reproducibility are welcome.

## Reporting data issues

Include the following when reporting a record-level issue:

- `record_id`
- affected field(s)
- current value and proposed correction
- supporting source or rationale

Do not submit personal data, passwords, private tokens, or unrelated copyrighted material.

## Change policy

- Canonical records are not silently rewritten.
- Corrections should be traceable and documented in `CHANGELOG.md`.
- Schema-breaking changes require a new major release.
- Derived datasets should be stored separately from the canonical release.
